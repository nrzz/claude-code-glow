# Roadmap

What could come next. None of it is promised; all of it is open to contributors. Comment on an issue or start a [discussion](https://github.com/nrzz/claude-code-glow/discussions) before a large change.

- More themes: Solarized Light, Nord Light and a high-contrast theme (palettes live in `src/palettes.mjs`).
- `claude-glow theme random` for a theme of the day.
- A Nerd Font preview in the README gallery.
- A HUD switch for the tip line.
